# Portfolio JM

Base estática del portfolio personal, construida con Astro, TypeScript y CSS nativo.

## Requisitos

- Node.js 22.12 o superior
- npm

## Comandos

```sh
npm install
npm run dev
npm run check
npm run build
npm run preview
```

## Estructura

- `src/pages/`: rutas del sitio; `/` es la versión española.
- `src/layouts/`: estructura documental compartida.
- `src/components/`: piezas reutilizables sin framework cliente.
- `src/data/site/`: contenido tipado por idioma.
- `src/i18n/`: configuración preparada para futuros idiomas.
- `src/styles/`: tokens visuales y estilos globales.
- `src/types/`: contratos TypeScript compartidos.
- `public/`: recursos estáticos, incluido el favicon JM.

La URL pública, el correo de contacto, el CV y los enlaces definitivos de proyectos se incorporarán cuando estén aprobados.
